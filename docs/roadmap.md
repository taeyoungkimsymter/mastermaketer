# 로드맵 — 후속 확장 명령 (모두 미구현)

> 아래 명령은 **스킬로 등록되어 있지 않습니다**(빈 명령을 작동하는 기능처럼 두지 않음). 설계만 정의합니다.

| 우선순위 | 명령 | 역할 체인 | 입력 | 출력/템플릿 | 의존성·제한 |
|---|---|---|---|---|---|
| 1 | /proposal | researcher → strategist → copywriter/pd → reviewer | 브리프, 조사 자료 | 인사이트 → 컨셉 3안 → 제안서 MD (`proposal.md` 신규) | 웹 검색 도구 있으면 사용. PPT 출력은 별도 |
| 2 | /shorts | strategist + copywriter + pd → reviewer | 브리프, N | 숏폼 N개: 훅·15초·30초 구성 | /video 의 콘티 검수 재사용 |
| 3 | /storyboard | pd → reviewer | 확정 스크립트 | 씬별 텍스트 콘티 CSV | 컨셉 선택 게이트 재사용 |
| 4 | /creator-guide | copywriter + pd → reviewer | 브리프, 채널 | 필수 멘션·금지사항·촬영 컷·광고 표기 확인사항 | 광고 표기 규정은 공식 출처 확인 필요(검증 전 "검토 필요") |
| 5 | /edit-note | pd | 피드백 텍스트, 타임코드 | 타임코드별 수정 지시 | 영상 직접 분석 불가 → 자막·프레임 요청 |
| 6 | /d-check | pd → reviewer | 촬영 계획 | D-3/D-1 최종 점검표 | **사용자가 호출할 때만 실행.** 스케줄러가 없으므로 자동 알림 약속 금지 |
| 7 | /risk-plan | pd | 일정·장소 | 위험 평가 + 대체안 (`risk-table.csv`) | 사진·주소 판단은 관찰/추정/확인 필요 구분 |
| 8 | /location-check | researcher + pd | 사진, 주소 | 헌팅 체크리스트 | 콘센트 용량·소음·면적·방위·허가는 확정 금지 |
| 9 | /wrap | comms-assistant + pd | 촬영 이슈·대응 결과 | 고객사 내부 기록 + 공통 노하우 **후보**(일반화, 사용자 확인 후 반영) 분리 | 노하우는 고객사명·제품명·개인정보·계약 조건 제거 |
| 10 | /compete | researcher → strategist | 기간(필수), 경쟁사 | 캠페인·메시지·채널 비교 | 웹 검색 필요. 기간 명시 없으면 중단 |
| 11 | /weekly | director | 고객사별 **승인된 최소 요약** | 주간 현황 | 다른 고객사 원본을 읽는 예외가 아님. 고객사 세션에서 `portfolio/approved-summaries/` 로 내보낸 요약만 집계. 별도 집계용 세션 필요 |

## 인프라 확장 (별도 인증·구성 필요)
Slack 봇, 모바일 화면, 예약 실행(스케줄러), 광고 API 연동, PPT/PDF/엑셀 출력, 웹 UI, 이미지 콘티 생성. 각각 도구 확보와 검증 방법 정의 후 추가.
