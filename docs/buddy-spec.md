# 데스크톱 버디 설계서

바탕화면 오른쪽 아래에 어카운트별 픽셀 캐릭터가 앉아 일하고, 확인할 일이 생기면 머리 위 말풍선으로 대표에게 알려 주는 기능이다.
시안: `docs/mockups/buddy/` (A 바탕화면 예시 · B 캐릭터 지정 · C 캐릭터 도감 · D 말풍선 3종 · 0 스프라이트 부품)

## 1. 원칙

- 마스터마케터 서버(127.0.0.1:8765)의 데이터와 상태 규칙을 그대로 쓴다. 버디가 따로 계산하지 않는다.
- 외부 통신 없음. 알림은 이 PC 안에서만 뜬다.
- 근거 데이터가 없는 알림은 만들지 않는다. (예: 매체 미연동이면 성과 이상 알림 없음)
- 예시 데이터(sample: true)에서 나온 알림에는 "예시" 표시를 붙인다.

## 2. 캐릭터

- 6명: 레오(카리스마) · 루나(멋쟁이) · 모모(귀여운) · 도윤(열정) · 하루(차분) · 준(힙)
- 2등신 꼬마 픽셀(24×28 격자). 생김새·색은 `docs/mockups/buddy/0-sprite.html` 스크립트의 `presets`와 그리기 코드를 그대로 옮긴다. (자동 외곽선, 상태별 얼굴, 이펙트 포함)
- 상태 5종: work(노트북 타이핑) · alert(손 들기 + 파란 ! 배지, 깡총) · urgent(땀 + 빨간 !! 배지, 깡총) · sleep(눈 감고 Zz) · idle
- 움직임은 steps() 애니메이션으로 1픽셀씩 툭툭. `prefers-reduced-motion`이면 정지.
- 캐릭터별 말투 예시는 시안 C의 "말투" 줄을 따른다.

## 3. 어카운트별 캐릭터 지정

- 저장: `clients/{id}/buddy.json` → `{"char": "momo"}`
- 화면: 어카운트 ⋯ 메뉴에 "캐릭터 지정" 추가. 시안 B처럼 6명 중 하나를 고르고, 말투 미리보기 말풍선을 보여 준다.
- 지정이 없으면 어카운트 순서대로 기본 캐릭터를 배정한다.

## 4. 상태와 말풍선 규칙

| 말풍선 | 색 | 캐릭터 상태 | 언제 |
|---|---|---|---|
| 확인 필요 | 핑크 · 하트 | alert | 컨펌 대기 결과물이 생겼을 때, 새 클라이언트 리퀘스트 |
| 체크 필요 | 노랑 · 별 | alert | 데드라인 하루 전인데 진행 중, 포스팅 전날 컨펌 표시 없음, 컨펌 대기 2일 초과 |
| 긴급 | 코랄 · 느낌표 | urgent | 데드라인 지난 리퀘스트·포스팅(Delayed), 성과 이상(데이터 있을 때만) |
| 없음 | — | work / sleep | 할 일 없으면 work, 방해 금지 시간이면 sleep |

- 말풍선 내용: "캐릭터명 · 라벨" 한 줄, 메시지 한 줄(캐릭터 말투), 버튼 `볼게요!` / `이따가`.
- 같은 어카운트 알림이 여러 개면 가장 급한 것 하나만 보여 주고 모서리에 `+N`.
- `볼게요!`: 기본 브라우저로 해당 어카운트의 해당 탭을 연다. (예: `http://127.0.0.1:8765/#acc=cj&tab=copy`)
- `이따가`: 그 알림을 10분 숨긴다.
- 캐릭터 클릭: 그 어카운트의 역할별 현황 패널(AE~MP) + `Overview 열기`.
- 할 일 없는 캐릭터 위에는 작은 회색 말풍선 "열일 중 · · ·".
- 방해 금지: 설정에서 시간대 지정(예: 19:00~09:00). 이 시간엔 모두 sleep, 긴급만 작은 배지.

## 5. 구조

- 서버: `GET /api/buddy` → 어카운트마다 `{id, name, char, state, alerts:[{level, role, text, tab, sample}]}`. 기존 상태 계산(딜레이, 컨펌 대기, 리퀘스트)을 재사용한다.
- 화면: `/buddy` 페이지. 배경 투명, 오른쪽 아래에 캐릭터들(시안 A의 나무 책상은 선택 사항, 기본은 끔). 30초마다 `/api/buddy`를 다시 읽는다.
- 바탕화면 창: `scripts/buddy.py`. pywebview로 테두리 없는·투명·항상 위 창을 화면 오른쪽 아래에 띄우고 `/buddy`를 연다. 창 크기는 캐릭터 수에 맞춰 작게(예: 520×360).
- 설치: pywebview는 처음 한 번 `pip install pywebview`가 필요하다. 설치가 어렵거나 실패하면, 일반 브라우저 창으로 `/buddy`를 여는 방식으로 대신하고 그 사실을 알린다.
- 실행: 마스터마케터 서버가 켜져 있을 때 `python3 scripts/buddy.py`. 서버가 꺼져 있으면 캐릭터들이 sleep 상태로 "서버가 꺼져 있어요" 말풍선을 띄운다.

## 6. 작업 순서

1. 스프라이트 그리기 코드를 `web/buddy-sprite.js`로 옮기고, 캐릭터 지정(⋯ 메뉴)과 `clients/{id}/buddy.json` 저장
2. `/api/buddy` + `/buddy` 페이지 (브라우저에서 먼저 확인)
3. `scripts/buddy.py`로 바탕화면 창 띄우기
4. 이따가·방해 금지·클릭 패널
