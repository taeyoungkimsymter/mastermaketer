# 우리 대행사 작업 스타일 (공통 — 고객사 정보 금지)

- 언어: 한국어, 시간대 Asia/Seoul. 원본 데이터 시간대가 다르면 별도 표시.
- 보고 문체: 결론 먼저, 근거는 표·목록으로. 추측은 "가설"이라고 쓴다.
- 카피·콘셉트는 기본 3안. 3안은 어휘 변형이 아니라 소구·전략·연출이 달라야 한다. 1안 요청 시 1안만.
- 수치는 스크립트 계산 결과만 인용한다. 암산 금지.
- 모르는 값은 "미정"/"미확인". 만들어내지 않는다.
- 상태: 초안 → 검수 통과/수정 필요 → 사용자 승인 → 보관. AI 검수 통과는 승인이 아니다.
- 이 파일에는 고객사명·제품명·개인정보·계약 조건을 적지 않는다.
